# Build roadmap

## Included in this ZIP
- Editorial responsive website and mobile layout.
- Search, category filter, latest/free/trending tabs.
- 30 departments and 150 subcategories.
- Free courses, free tools, tricks, hidden gems, upcoming and independent creator discovery zones in the UI.
- Real public collectors for GitHub, Hugging Face and Hacker News.
- Scheduled scan orchestration, scan history, source status and exact-URL deduplication.
- Token-protected scan and explicit-save extension APIs.
- Chrome extension with manual save, category and note.
- Issue report endpoint and documentation.
- Footer attribution: Created by Shivank Dwivedi.

## Next implementation milestones
1. PostgreSQL schema, migrations, user auth and role-based admin.
2. RSS connector with per-feed allowlist, quotas and source registry UI.
3. Course connectors with verified course, certificate, deadline and language metadata.
4. Pricing verification and free-tier history.
5. Official company changelog and roadmap connectors; upcoming status evidence.
6. Research connectors (arXiv, OpenAlex, Crossref) and evidence records.
7. Social integrations using official APIs only.
8. Translation pipeline for Hindi / English / Hinglish.
9. Independent worker queue, retries, rate limits and dead-letter handling.
10. Real Admin Studio, notifications, watchlists, collections and analytics.
11. E2E, accessibility, dependency and security tests.
12. Production deployment, monitoring, backups and recovery tests.
