# Source policy

1. Prefer official APIs, RSS feeds, changelogs and public project metadata.
2. Record source identity, URL, access method, quota, terms, last scan and errors.
3. Never bypass authentication, private groups, paywalls, CAPTCHAs or platform controls.
4. Social discovery requires official API access or permitted public/indexed content.
5. Distinguish original publication date, source update date and OPENINFO discovery date.
6. Distinguish free, freemium, trial, paid, credit-based and open-source/licence status.
7. Do not call an item verified merely because a page exists. Current `Source-linked` means provenance URL exists.
8. Upcoming status must be backed by an official announcement or roadmap; label rumours separately.
9. Respect per-source quotas and exponential backoff; never retry indefinitely.
10. Provide corrections and retain the source trail.
